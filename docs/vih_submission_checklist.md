# Value in Health — Original Research submission checklist (verified 2026-09-24)

Sources: Guide for Authors https://www.ispor.org/publications/journals/value-in-health/for-authors/guide-for-authors ; Submit https://www.ispor.org/publications/journals/value-in-health/for-authors/submit ; ISPOR AI Policy https://www.ispor.org/ai-policy ; Elsevier GenAI policy (June 2026) https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals

| # | Item | Requirement |
|---|---|---|
| 1 | Article type | Original Research ("instrument development" / "policy analysis" explicitly listed) |
| 2 | Word count | ≤4,000, excluding abstract, references, figure legends, tables, appendices |
| 3 | Tables + figures | ≤6 combined; figure parts (1A, 1B) count separately |
| 4 | Title | ≤25 words, title case |
| 5 | Abstract | Structured: Objectives / Methods / Results / Conclusions; ≤250 words |
| 6 | Keywords | 3–6 |
| 7 | Highlights | 3 statements, ≤120 words total: (1) gap addressed, (2) key findings, (3) implications for decision making / HEOR |
| 8 | Précis | ≤25 words, not a restatement of the title (title page) |
| 9 | Body | Introduction, Methods, Results, Discussion, Conclusions; no footnotes; sensitivity analysis required for modeling |
| 10 | Format | 12-pt Times New Roman, double-spaced, 1-inch margins, US Letter; page numbers bottom-centre from abstract page; H1 bold, H2 bold italic; no line numbers, no field cross-references; .docx |
| 11 | Blinding | Double-anonymized. No author names, affiliations, acknowledgments in the main file |
| 12 | AI statement (manuscript) | Headed section immediately before References. Title: "Declaration of generative AI and AI-assisted technologies in the manuscript preparation process". Text: "During the preparation of this work, the author(s) used [TOOL] in order to [REASON]. After using this tool/service, the author(s) reviewed and edited the content as needed and take(s) full responsibility for the content of the published article." |
| 13 | AI statement (title page) | "Use of AI: ..." with tool name, purpose, extent of oversight |
| 14 | AI in Methods | Where AI is part of the research method (e.g., code development), describe reproducibly in Methods: model/tool name, version, developer, tasks, human verification. Cite ELEVATE-GenAI (Fleurence et al. Value Health 2025;28(11):1611-1625) |
| 15 | AI images | No AI-generated data figures unless produced by reproducible code reported in Methods; no AI graphical abstract; AI is not an author and not a reference |
| 16 | References | Superscript Arabic numerals in citation order; AMA style; abbreviated journal names; first 3 authors + et al when ≥6; DOI optional but include |
| 17 | Figures | Separate files (AI/EPS/PDF/SVG/PPT preferred; else TIFF/PNG ≥300 dpi at 3"×5"); titles and legends on a separate page after References; colour free online |
| 18 | Tables | Editable Word/Excel; not embedded in text; after References or uploaded separately; abbreviations alphabetised below each table |
| 19 | Supplement | Allowed; posted as submitted; state whether for publication or review only; counts on title page |
| 20 | Title page | Title; authors (name, degrees, dept/institution, city/country); corresponding author; Précis; word count; pages; figures; tables; appendix counts; "Authorship Confirmation: All authors certify that they meet the ICMJE criteria for authorship."; Funding/Support; Role of the Funder/Sponsor; Use of AI; Acknowledgments |
| 21 | Cover letter | To editors-in-chief; title; interest to VIH readers and contribution; proprietary data/model statement; funding; sponsor role; corresponding author contact; mention any preprint |
| 22 | Data/code | Must provide data on editor request. Recommended Transparency Statement (protocol, preregistration, data access link, code sharing, reporting checklist) per Wang & Pottegård Am J Epidemiol 2024;193(11):1625-1631 for open-science badge |
| 23 | Patient engagement / sex-gender | Statement whether patients were engaged (ISPOR definition); address sex/gender dimension or state as limitation |
| 24 | Ethics | No explicit item; add a Methods sentence: publicly available aggregate data, no human subjects |
| 25 | Authors | ≤10; ICMJE criteria; Authorship Form PDF at revision/acceptance; COI via AAMC Convey |
| 26 | Preprint | Contact viheditor@ispor.org before posting; disclose in cover letter |
| 27 | Submit | ScholarOne https://mc.manuscriptcentral.com/valueinhealth |
| 28 | Timelines | Desk decision ~2 weeks; reviewed decision 6–8 weeks; 2025 rejection rate 82% |
